# Phase 2 — Security Constitution

## Purpose

Phase 2 encodes the lessons, principles, and operational guidance distilled from Phase 1
(the taxonomy: design-shape register, discovery-signal register, and feature-abuse catalog)
into the **Security Constitution** — the core intellectual contribution of the framework. The
Constitution is the artifact a model consumes to operationalize design-flaw reasoning.

## Relationship to Phase 1

Phase 1 supplies the taxonomy — the Design Shape Register, Discovery Signal Register, and
Feature-Abuse Reference. Phase 2 consumes those artifacts and turns them into promptable
guidance: first principles, the reasonable-customer test, the Anchors of Trust,
discovery-signal routing guidance, calibration guidance, and operational lessons from
validated findings.
